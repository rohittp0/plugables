# Plugables

Gradle plugins for Android and Kotlin Multiplatform projects.

| Plugin | Description | Docs |
|--------|-------------|------|
| [viewmodel-stub](viewmodel-stub/) | Generates an interface and preview-safe stub from ViewModels annotated with `@ViewModelStub` | https://rohittp.com/plugables/viewmodel-stub |
| [typed-events](typed-events/) | Generates shared typed analytics APIs, a native sink, Swift facade, and parity schema from YAML | https://rohittp.com/plugables/typed-events |
| [codeview](codeview/) | Generates an interactive HTML report of `@Preview` screens with per-composable click-to-IDE overlays | [codeview/README.md](codeview/README.md) |
| [proto-extended](proto-extended/) | Generates Kotlin metadata plus Compose Multiplatform `StringResource`/`DrawableResource` accessors from protobuf enum options | https://rohittp.com/plugables/proto-extended |
